# PPT 模板学习器 (pptx-template-learner)

从已有PPT中**逆向提取设计规范**，参考规范生成新PPT。

## 核心理念

**有模板参考，无模板自由。模板是参考底色，不是紧箍咒。**

- 有模板 → 参考模板的配色/字体/布局/动画风格，自由度可调
- 无模板 → 自由发挥，做出好看专业的PPT

## 功能

- 🔍 **分析PPT规范**：从PPT提取配色、字体、布局、动画、转场、目录结构等完整规范
- 📁 **模板库管理**：按主题归档PPT及规范，支持增删查改
- 🎨 **按规范生成**：参考模板风格生成新PPT，自由度可调（高/中/低）

## 自由度

| 自由度 | 含义 | 适用场景 |
|--------|------|----------|
| **高**（默认） | 参考模板气质，灵活发挥 | 日常使用、灵活展示 |
| **中** | 较多遵循模板 | 部门内统一风格 |
| **低** | 高度还原模板 | 品牌要求严格、客户指定 |

## 脚本

| 脚本 | 用途 |
|------|------|
| `scripts/analyze_pptx.py` | 从PPT提取完整spec.json |
| `scripts/template_manager.py` | 模板库增删查改 |
| `scripts/generate_from_spec.js` | 根据spec+内容+自由度生成PPT |

## 依赖

- Python 3 + python-pptx（分析）
- Node.js + pptxgenjs（生成）
